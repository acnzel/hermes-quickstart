# 시작 전 준비물

세팅을 시작하면 에이전트가 대부분을 알아서 한다. 다만 아래는 사람만 할 수 있고, 준비가 안 돼 있으면
중간에 멈춘다. **시작하기 전에 전부 갖춰 둔다.**

2026-11-23 실제 실행에서 사람이 손댄 지점을 기준으로 적었다. 확인하지 못한 것은 "미확인"이라고 적는다.

## 1. 준비물 체크리스트

### 컴퓨터에 설치

| 준비물 | 왜 필요한가 | 확인 방법 |
|---|---|---|
| macOS | 지금은 macOS 에서만 검증했다 | |
| Aside 브라우저와 CLI | 에이전트가 Oracle·디스코드 화면을 조작한다 | 터미널에서 `aside --version` |
| 코딩 에이전트 (Codex CLI 또는 Claude Code) | 이 레포의 지시문을 읽고 세팅을 진행한다 | |

Aside 는 유료 크레딧이 없어도 된다. 이 레포는 스크립트 실행(`aside repl`)만 쓰고, 이건 크레딧을 쓰지 않는다.
크레딧이 0 인 상태에서 끝까지 진행되는 것을 확인했다.

### 계정

| 준비물 | 왜 필요한가 | 미리 해 둘 것 |
|---|---|---|
| Oracle Cloud 계정 | 무료 VM | 가입, 카드 등록, 홈 리전 선택까지 끝낸다. 홈 리전은 나중에 못 바꾼다 |
| ChatGPT Plus 이상 | Hermes 가 이 구독으로 모델을 호출한다 | 로그인할 수 있는 상태면 된다 |
| 디스코드 계정 | 봇을 만들고 대화한다 | 아래 "2단계 인증" 을 반드시 확인한다 |
| 디스코드 서버 | 봇이 들어갈 곳 | 본인이 만든 서버를 하나 준비한다. 서버 이름을 에이전트에게 알려 준다 |

### 손 닿는 곳에 둘 것

| 준비물 | 언제 쓰나 |
|---|---|
| **디스코드 2단계 인증 앱** (Google Authenticator, Authy 등이 깔린 폰) | 봇 토큰을 발급할 때 6자리 코드를 요구한다. 폰이 옆에 없으면 여기서 멈춘다 |
| ChatGPT 에 로그인된 브라우저 | 기기 승인 코드를 입력한다. 코드는 15분 뒤 만료된다 |

디스코드 계정에 2단계 인증이 꺼져 있을 때 토큰 발급 화면이 무엇을 요구하는지는 미확인이다.
2단계 인증을 켠 계정으로만 검증했다.

### Aside 에서 미리 로그인

에이전트는 로그인 화면을 넘기지 못한다. 시작 전에 Aside 브라우저에서 아래 세 곳에 로그인해 둔다.

1. `cloud.oracle.com` (Oracle 콘솔)
2. `discord.com/developers/applications` (디스코드 개발자 포털)
3. `chatgpt.com`

Oracle 콘솔은 몇 시간 뒤 로그인이 풀린다. 시작 직전에 로그인한다.

## 2. 사람이 손대는 순간 (시간순)

세팅은 40분쯤 걸리고, 그중 25분은 Hermes 설치를 기다리는 시간이다.
사람은 아래 5번만 나서면 된다. 에이전트가 그때마다 무엇을 하라고 알려 준다.

| 순서 | 시점 | 화면에 뜨는 것 | 할 일 | 필요한 것 |
|---|---|---|---|---|
| 1 | VM 과 Hermes 설치가 끝난 뒤 | 에이전트가 주소와 `XXXX-XXXXX` 코드를 보여 준다 | `auth.openai.com/codex/device` 를 열어 코드 입력 | ChatGPT 로그인. **15분 안에** |
| 2 | 디스코드 앱 생성 | "잠깐! 로봇 아니고 사람 맞죠?" | "사람입니다" 를 누른다 | |
| 3 | 봇 토큰 발급 | "다단계 인증" 창 | 6자리 코드를 넣고 제출 | **2단계 인증 앱** |
| 4 | 봇을 서버에 초대 | "잠깐! 로봇 아니고 사람 맞죠?" | "사람입니다" 를 누른다 | |
| 5 | 마지막 | 디스코드 서버의 홈 채널 | 멘션 없이 메시지를 보낸다. 봇이 답하면 끝 | |

3번에서 토큰이 화면에 한 번만 표시된다. **그 화면을 닫거나 새로고침하지 않는다.** 에이전트가 읽어서 VM 에 넣는다.
사람이 토큰을 복사할 필요는 없다.

다른 채널에서 봇을 부를 때는 `@` 자동완성에서 **"앱" 표시가 붙은 쪽**을 고른다. 같은 이름의 역할이 함께 뜨는데,
역할을 고르면 봇이 답하지 않는다. 홈 채널은 멘션 없이 답하도록 세팅된다.

1~4번은 사람이 자리에 있어야 한다. 순서 1 의 코드는 15분 뒤 만료되고, 만료되면 에이전트가 새 코드를 띄운다.

## 3. 에이전트가 사람 대신 하는 것

미리 알아 두면 좋은 것들이다. 시작할 때 한 번 동의를 받는다.

- 디스코드 개발자 약관 동의 체크 (새 앱을 만들 때 필요하다)
- 봇 토큰을 발급해서 VM 의 `~/.hermes/.env` 에 저장 (권한 600). 값은 채팅에 표시하지 않는다
- ChatGPT 구독 인증 정보를 VM 의 `~/.hermes/auth.json` 에 저장 (Hermes 가 한다)
- Oracle VM 생성. Always Free 범위(VM.Standard.E2.1.Micro) 밖의 자원은 만들지 않는다
