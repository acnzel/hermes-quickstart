# hermes-quickstart

내 전용 AI 비서를 무료 서버에 올리고 디스코드에서 부르는 방법을 담은 레포입니다.
개발자가 아니어도 따라 할 수 있게 만드는 것이 목표입니다. 화면을 클릭하고 명령을 입력하는 일은 코딩 에이전트가 대신 합니다.

[Hermes Agent](https://github.com/NousResearch/hermes-agent)는 Nous Research 가 만든 오픈소스 AI 에이전트입니다.
이 레포는 Nous Research 와 관계없는 비공식 가이드입니다.

## 이런 분을 위한 레포입니다

- ChatGPT 를 구독해서 쓰고 있고, "AI 에이전트"가 궁금한데 어디서 시작할지 모르겠다.
- 서버나 터미널을 다뤄 본 적이 없다.
- 돈을 더 내지 않고 한번 써 보고 싶다.

## ChatGPT 와 무엇이 다른가

ChatGPT 는 내가 앱을 열고 물어볼 때 답하는 서비스입니다. Hermes 는 내 서버에서 24시간 켜져 있는 프로그램입니다.
이 레포대로 세팅하면 두뇌는 같습니다. Hermes 가 내 ChatGPT 구독으로 OpenAI 모델을 부르기 때문입니다.
다른 점은 그 두뇌가 어디서, 무엇을 가지고 일하느냐입니다.

| | ChatGPT (구독) | Hermes (이 레포로 세팅) |
|---|---|---|
| 어디서 쓰나 | ChatGPT 앱과 웹 | 디스코드. 텔레그램, 슬랙 등도 지원합니다 |
| 언제 도나 | 내가 열었을 때 | 서버에서 24시간 |
| 자기 컴퓨터 | 대화 안의 임시 공간 | 서버 한 대를 통째로 씁니다. 명령을 실행하고 파일을 남깁니다 |
| 기억 | OpenAI 가 관리 | 내 서버의 파일(`MEMORY.md`, `USER.md`)에 쌓입니다. 직접 열어 보고 고칠 수 있습니다 |
| 먼저 말 걸기 | 주로 내가 먼저 묻습니다 | 정해 둔 시간에 디스코드로 보고하도록 예약할 수 있습니다 |
| 배우기 | | 복잡한 일을 끝내면 방법을 "스킬"로 저장해 다음에 재사용합니다 |
| 모델 | OpenAI | 바꿀 수 있습니다. Claude, 로컬 모델 등 |
| 데이터 위치 | OpenAI 서버 | 대화 기록과 기억은 내 서버에. 모델 호출 내용은 모델 회사로 갑니다 |

ChatGPT 도 기억과 예약 기능을 계속 넣고 있어서, 기능 목록만 보면 겹치는 것이 많습니다.
실제 차이는 두 가지입니다. Hermes 는 자기 서버를 가지고 있고, 그 서버와 설정을 내가 통제합니다.

### ChatGPT 가 더 나은 점

Hermes 가 항상 좋은 것은 아닙니다.

- 설치가 필요 없습니다. Hermes 는 이 레포의 과정을 거쳐야 합니다.
- 빠릅니다. 이 레포의 구성에서 Hermes 는 메시지 하나에 답하는 데 16초가 걸렸습니다.
- 이미지 생성, 음성 대화 같은 기능이 앱에 다 들어 있습니다.
- 고장 나면 OpenAI 가 고칩니다. Hermes 는 내가 관리합니다.

### Hermes 로 할 수 있는 일

이 레포에서 직접 확인한 것:

- 디스코드에서 대화하기
- 서버에서 명령을 실행하고 결과 알려 주기 (예: "지금 어디서 돌고 있어?"에 서버 이름을 확인해 답했습니다)
- 서버에서 디스코드로 메시지 보내기

공식 문서가 설명하지만 이 레포에서는 아직 확인하지 않은 것:

- 예약 작업: "매일 아침 9시에 이것을 조사해서 알려 줘"
- 대화가 끝나도 이어지는 기억, 지난 대화 검색
- 스킬 만들기와 개선
- 여러 작업을 하위 에이전트에게 나눠 맡기기

기능 전체는 [공식 문서](https://hermes-agent.nousresearch.com/docs/)에 있습니다.

### 다른 사람들은 어디에 쓰나

공개된 글에서 고른 다섯 가지입니다. 이 레포에서 해 본 것은 아닙니다.

- 영업 문의 처리: 문의 접수부터 견적서, 세금계산서 요청까지
- 정기 브리핑과 모니터링: 매일 뉴스, 주간 조사
- 가격 감시와 리드 발굴: 시세보다 싼 매물 알림
- 가족·소규모 팀 공용 비서: 메신저 하나에서 여럿이 같이
- 오류 분석과 배포 전 점검: 읽기와 요약부터

사례별 출처와 이 레포 구성에서 더 필요한 것은 [docs/use-cases.md](docs/use-cases.md) 에 있습니다.

## 비용

| 항목 | 비용 |
|---|---|
| Oracle Cloud 서버 | 무료 (Always Free). 가입할 때 카드 등록이 필요합니다 |
| ChatGPT Plus 이상 | 이미 내고 있는 구독료. 추가 비용 없음 |
| 디스코드 | 무료 |
| Aside 브라우저 | 무료. 유료 크레딧 없이 됩니다 |

알아 둘 것:

- Hermes 는 내 ChatGPT 구독의 사용 한도 안에서 모델을 부릅니다. Hermes 를 많이 쓰면 ChatGPT 쪽 한도에 영향이 있을 수 있습니다. 얼마나 쓰는지는 확인하지 못했습니다.
- ChatGPT 구독을 Hermes 같은 외부 프로그램에서 쓰는 것에 대해, OpenAI 와 Hermes 문서 어디에서도 명시된 허용 문구를 찾지 못했습니다. Hermes 가 공식 기능으로 지원하고 있지만, 정책이 바뀔 수 있습니다.
- 구독으로는 일부 모델만 쓸 수 있습니다. 아래 "모델" 절을 보세요.
- Claude 를 쓰려면 Anthropic API 키가 필요하고, 쓴 만큼 돈이 나갑니다. 이 레포의 기본 구성은 아닙니다.

## 지금 이 레포의 상태

2026-11-23 에 한 계정으로 처음부터 끝까지 한 번 진행해서 동작을 확인했습니다.
그 과정의 명령, 측정값, 막힌 곳을 전부 `docs/golden-path.md` 에 적었습니다.

그 뒤에 그 과정을 에이전트용 지시문(`AGENTS.md`)과 스크립트로 묶었습니다.
서버 쪽 스크립트(`scripts/vm-hermes.sh`)는 세팅된 서버에서 명령별로 다시 돌려 확인했습니다.

아직 안 된 것:

- 빈 서버에서 `AGENTS.md` 만으로 처음부터 끝까지 다시 세팅해 보지 않았습니다.
- macOS 에서만 해 봤습니다.
- 다른 사람의 새 계정으로는 해 보지 않았습니다.
- 디스코드 화면 조작은 한국어 화면에서만 확인했습니다.

## 시작하기

### 1. 준비물을 갖춥니다

[docs/prerequisites.md](docs/prerequisites.md) 를 먼저 읽습니다. 요약하면 이렇습니다.

- 설치: Aside 브라우저, 코딩 에이전트(Codex CLI 또는 Claude Code)
- 계정: Oracle Cloud(카드 등록까지), ChatGPT Plus 이상, 디스코드, 내가 만든 디스코드 서버 하나
- 옆에 둘 것: 디스코드 2단계 인증 앱이 깔린 폰
- Aside 에서 미리 로그인: Oracle 콘솔, 디스코드 개발자 포털, ChatGPT

### 2. 코딩 에이전트에게 맡깁니다

이 레포를 받아서 코딩 에이전트로 엽니다.

```bash
git clone https://github.com/acnzel/hermes-quickstart.git
cd hermes-quickstart
```

그리고 이렇게 말합니다.

```
Hermes 세팅해 줘. 디스코드 서버 이름은 "<내 서버 이름>" 이야.
```

에이전트는 이 레포의 `AGENTS.md` 를 읽고 순서대로 진행합니다.

### 3. 중간에 다섯 번 나섭니다

세팅은 40분쯤 걸립니다. 그중 25분은 설치를 기다리는 시간입니다. 사람은 아래 다섯 번만 손대면 됩니다.

| 순서 | 화면에 뜨는 것 | 할 일 |
|---|---|---|
| 1 | 에이전트가 주소와 코드(`XXXX-XXXXX`)를 보여 줍니다 | 주소를 열어 ChatGPT 로 로그인하고 코드를 넣습니다. 15분 안에 |
| 2 | "잠깐! 로봇 아니고 사람 맞죠?" | "사람입니다"를 누릅니다 |
| 3 | "다단계 인증" | 인증 앱의 6자리 코드를 넣습니다. 그 뒤 화면은 닫지 않습니다 |
| 4 | "잠깐! 로봇 아니고 사람 맞죠?" | "사람입니다"를 누릅니다 |
| 5 | 디스코드 서버 | 채널에 아무 말이나 보냅니다. 봇이 답하면 끝입니다 |

### Aside 를 쓸 수 없다면

Aside 를 설치하지 않았거나 화면 조작이 실패하면, 브라우저에서 누르는 일만 직접 하면 됩니다.
서버 설치와 설정은 그대로 에이전트가 합니다. 어떤 브라우저든 됩니다.
클릭 순서는 [docs/manual-fallback.md](docs/manual-fallback.md) 에 있습니다.

Aside 의 유료 크레딧이 떨어진 것은 문제가 되지 않습니다. 이 레포는 크레딧을 쓰지 않는 기능만 씁니다.

## 세팅이 끝나면

### 대화하기

봇이 들어온 채널에 그냥 메시지를 보내면 됩니다. 멘션은 필요 없습니다.

다른 채널에서 부를 때는 `@` 를 치고 **"앱" 표시가 붙은 쪽**을 고릅니다.
같은 이름의 역할이 함께 뜨는데, 역할을 고르면 봇이 답하지 않습니다.

### 자동 업데이트

매주 월요일 새벽 4시에 Hermes 가 스스로 업데이트합니다. 필요하면 재시작까지 알아서 합니다.

- 버전이 바뀌면 디스코드로 알려 줍니다.
- 업데이트에 실패하거나 봇이 다시 올라오지 않으면 디스코드로 알려 줍니다.
- 바뀐 것이 없으면 아무 말도 하지 않습니다.

설치 스크립트는 `scripts/install-weekly-update.sh`, 기록은 서버의 `~/.hermes/logs/weekly-update.log` 에 남습니다.

### 모델

ChatGPT 구독으로 되는 모델과 안 되는 모델이 있습니다. 2026-11-23 에 하나씩 불러 본 결과입니다.

| 모델 | 결과 |
|---|---|
| `gpt-5.6-luna` | 됨. 가볍습니다 |
| `gpt-6-luna` | 됨 |
| `gpt-6-sol` | 됨 |
| `gpt-5-nano`, `gpt-5-mini`, `gpt-5.4-mini` | 안 됨. OpenAI 가 거절합니다 |

안 되는 모델로 설정하면 봇이 모든 메시지에 오류로 답합니다. 모델을 바꾼 뒤에는 꼭 한 번 말을 걸어 확인하세요.

### 서버에서 직접 확인하기

```bash
ssh -i ~/.ssh/oracle.key ubuntu@<서버 IP>
systemctl --user status hermes-gateway      # 봇이 켜져 있는지
tail -f ~/.hermes/logs/gateway.log          # 봇이 무엇을 하는지
systemctl --user restart hermes-gateway     # 재시작
```

## 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| 멘션했는데 답이 없다 | 봇이 아니라 같은 이름의 역할을 멘션했을 가능성이 큽니다. "앱" 표시가 붙은 쪽을 고르세요 |
| 모든 메시지에 오류로 답한다 | 구독으로 안 되는 모델이 설정됐습니다. `hermes config set model.default gpt-5.6-luna` |
| ChatGPT 승인 코드가 안 먹는다 | 15분이 지났습니다. 에이전트에게 새 코드를 달라고 하세요 |
| Oracle 서버에 접속이 안 된다 | 공인 IP 가 안 붙었을 수 있습니다. `docs/golden-path.md` 의 "확인된 함정" 2번 |
| Oracle 에서 한국 리전을 고를 수 없다 | 가입할 때 자리가 없으면 안 뜹니다. 일본 리전도 동작에 문제 없습니다. 나중에 바꿀 수는 없습니다 |

막힌 곳과 해결 과정은 [docs/golden-path.md](docs/golden-path.md) 에 더 자세히 있습니다.

## 알아 둘 한계

- 서버 메모리가 1GB 입니다. 대화 직후 봇이 391MB 를 썼고 여유는 385MB 였습니다. 무거운 작업에서는 느려지거나 멈출 수 있습니다.
- 웹 브라우저 기능은 설치하지 않았습니다. 메모리가 모자랍니다.
- Oracle 무료 서버는 계정당 2대까지입니다.

## 안전에 관해

- Hermes 는 서버에서 명령을 실행할 수 있습니다. 봇에게 말을 걸 수 있는 사람은 그 서버를 조작할 수 있는 사람입니다.
- 그래서 디스코드 서버를 만든 본인 한 명만 대화할 수 있게 세팅합니다 (`DISCORD_ALLOWED_USERS`). 다른 사람을 추가하기 전에 이 점을 생각하세요.
- 봇 토큰과 ChatGPT 인증 정보는 서버의 `~/.hermes/` 에만 저장합니다. 세팅 중에도 채팅에 값을 표시하지 않습니다.
- 토큰이 노출됐다면 디스코드 개발자 포털에서 "토큰 초기화"를 누르면 이전 토큰은 바로 무효가 됩니다.

## 그만 쓰고 싶을 때

1. Oracle 콘솔에서 인스턴스를 Terminate 합니다. 서버와 그 안의 데이터가 지워집니다.
2. 디스코드 개발자 포털에서 앱을 삭제합니다.
3. ChatGPT 설정에서 연결된 기기(Codex) 접근을 해제합니다.
